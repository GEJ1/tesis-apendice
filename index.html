Repositorios de código y recursos digitales

Repositorios de código abierto desarrollados, mejorados o utilizados extensivamente durante esta tesis. Cada enlace apunta a la versión estable del código fuente y su documentación técnica.

A.1 · Plataforma DataPruebas Caps. 4, 5 y 6

Infraestructura para la recolección de datos multimodales en entornos web. Sistema de gestión de participantes, integración de tareas cognitivas y almacenamiento persistente de trayectorias.

Plataforma: datapruebas.org

A.2 · Implementación del Virtual Chin Rest de Li et. al 2020 Cap. 5 y 6

Permite medir la distancia entre el participante y la pantalla. También permite ajustar el contenido de la página de jsPsych a una dimensión física conocida (por ejemplo, garantizando que un estímulo de 200 píxeles de ancho tenga 2,2 cm de ancho en el monitor del participante).

Plugin oficial: jspsych.org · virtual-chinrest

A.3 · Repositorio de tareas cognitivas implementadas en jsPsych Cap. 5

Go/NoGo, Change Detection Task y Trail Making Test, este último con su propio plugin de jsṔsych que permite armar distintas versiones

Repositorio de tareas: https://github.com/GEJ1/Neuro_psych_tasks/

A.4 · Biblioteca NeuroTask Cap. 4

Librería en Python para el preprocesamiento de series temporales conductuales y la extracción de características cinemáticas de alta resolución. Interpolación de señales, segmentación de estados basada en velocidad (Búsqueda, Desplazamiento, Vacilación) y cálculo de métricas SHAP.

Repositorio: https://github.com/NeuroLIAA/neurotask

A.4 · Biblioteca Pyxations Cap. 5

Pyxations es una biblioteca de Python diseñada para analizar datos de seguimiento ocular, tanto si se trabaja con datos brutos como con conjuntos de datos procesados. Ayuda a investigadores y desarrolladores a extraer información útil a partir de movimientos oculares complejos utilizando el ecosistema de Python.

Repositorio: https://github.com/NeuroLIAA/neurotask

A.5 · Seguimiento ocular web · WebGazer Cap. 5

Modificaciones y validaciones técnicas sobre el sistema de eye-tracking remoto por cámara web. Migración a TensorFlow.js (Facemesh), detección de parpadeos (EAR) y calibración explícita de 9 puntos.

Núcleo WebGazer: github.com/NeuroLIAA/WebGazer Validación antisacadas: github.com/GEJ1/et_webcam_experiments
